# The Light She Left Behind

A small farewell experience for Nour — a moonlit 3D garden you walk through on your phone,
collecting keepsakes and inside jokes until the final letter arrives from the sky.

Built with Vite, React, React Three Fiber, and drei. Designed for **iPhone (landscape)**;
also works on desktop with WASD + mouse drag.

## Run it

```bash
npm install
npm run dev       # local dev server
npm run build     # production build into dist/
npm run preview   # serve the production build
```

To try it on a phone on the same Wi-Fi: `npm run dev -- --host`, then open the Network URL.

## The experience

- Open the envelope, walk through the Moon Gate.
- Five landmarks: Rose Cabinet, Lantern Grove, Starlit Path, Moon Bench, and the White-Rose Arch.
- Collect all 14 memories to unlock the final letter.
- The garden also hides **4 secrets**: something in the sky, something fluffy,
  something that runs away, and something famously unfinished. Tap what looks curious.
